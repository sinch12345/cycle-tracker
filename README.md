# Cycle Tracker

A private, offline-first period tracking app built with React Native and Expo.

## Features
- Cycle, ovulation and fertile window predictions
- Calendar with period logging
- Daily log for flow, symptoms, mood and notes
- Insights (cycle history, common symptoms and moods)
- Optional PIN and biometric lock
- Period reminders
- Data export and one-tap delete
- Cycle data stays on the device
- Optional end-to-end encrypted partner sharing (off by default, stoppable any time)
- On-device assistant (Aura): no AI service, no internet needed

## Getting started
```bash
npm install
npx expo start
```
Open the app with Expo Go on your phone.

## Disclaimer
Predictions are estimates based on logged history. This app is not a medical device and must not be used for contraception or diagnosis.
